# Code of Conduct

## Our pledge
We want OpenAir KZ to be a welcoming, harassment-free project for everyone, regardless of age, background, gender, nationality, language, experience level, or ability.

## Expected behavior
- Be respectful and constructive in Issues, Pull Requests and reviews.
- Welcome newcomers and answer questions patiently, in English, Russian or Kazakh.
- Give and accept feedback gracefully; focus on the work, not the person.

## Unacceptable behavior
- Harassment, insults, discrimination, or personal attacks.
- Publishing others' private information.
- Spam or unrelated promotion.

## Enforcement
Maintainers may edit or remove comments, close Issues or Pull Requests, and block contributors who violate this Code of Conduct.
To report a problem, contact a maintainer listed in the README directly (not in a public Issue).
