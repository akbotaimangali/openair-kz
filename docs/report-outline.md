# Report outline (3-20 pages, submit as PDF or DOCX)

Each member writes their own section in their own words. Do not paste AI text unchanged: you may be asked to explain and defend it.

1. **Title page:** project name, team, roles, **working GitHub link**, date
2. **Project explanation:** what it is, why it exists, problem, users (half a page)
3. **Concept:** SDG alignment (with targets), DPG justification (9 indicators, honest gaps), personas, value proposition
4. **Market analysis:** verified competitors, SWOT, positioning chart
5. **Design decisions:** stack, licence (MIT vs alternatives, SIS licensing), architecture, data source, why static site, privacy choices
6. **Connection to course concepts:** table SIS 1-15 → how you used it
7. **Implementation:** features, how to run, tests, CI, Dependabot
8. **GitHub collaboration:** branches, PRs, reviews, Issues (with screenshots)
9. **Screenshots:** GitHub repo, commits, prototype, tools used
10. **Team contribution:** table who did what
11. **AI usage disclosure:** tools, how, for what tasks
12. **Reflection and future work:** limits (model data), next steps
